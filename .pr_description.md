🎨 Palette: Add keyboard focus states to sidebar navigation

* 💡 What: Added `focus-visible` utility classes to the sidebar navigation tabs and logout button in `Dashboard.jsx`.
* 🎯 Why: Core navigation elements need explicit keyboard focus states to be visible, especially on darker themes.
* 📸 Before/After: Focus state is now clearly outlined in emerald/red instead of relying on default browser styling which was nearly invisible.
* ♿ Accessibility: Improved keyboard navigation support and removed redundant `aria-label` attributes on buttons that already contained visible text, ensuring compliance with WCAG 2.5.3 (Label in Name).
