## 2024-10-24 - Improve empty state accessibility for History export
**Learning:** Found an accessibility issue pattern in icon-only or primary action buttons on empty state views (like History Panel when there is no data). Without `disabled`, users might be confused about why actions don't work, and without `title` or tooltip, disabled states are inaccessible. Also, screen readers read decorative SVG icons unless explicitly hidden with `aria-hidden="true"`.
**Action:** When implementing primary buttons in panels that might have empty states (e.g., tables without data), proactively add `disabled={data.length === 0}` and conditionally render a `title` explaining why it's disabled. Use `focus-visible:ring-2 focus-visible:ring-emerald-500` to support keyboard navigation when focused. Always hide decorative SVGs inside buttons with `aria-hidden="true"`.
