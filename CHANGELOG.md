## [1.0.0] — 2025-05

### Added
- YOLOv8 real-time bird counting and behavior detection pipeline
- WebRTC live video streaming with aiortc
- IoT sensor fusion: temperature, humidity, ammonia, acoustic anomaly
- Autonomous FSM actuator control (ventilation, heating)
- ESG compliance PDF report generation (ReportLab)
- RBAC + JWT authentication with Supabase Auth
- OAuth support (Google, GitHub) via Supabase
- React + Vite admin dashboard with Recharts graphs
- React Native (Expo) mobile monitoring app
- Docker Compose deployment with Cloudflare Tunnel support
- Plugin system for extensible AI modules
- mTLS edge security architecture
- Supabase PostgreSQL integration with local SQLite fallback
- Supabase background sync worker
